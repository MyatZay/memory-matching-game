# Memory Matching Game

A React memory matching game with 20 shuffled cards. Each number from 1 to 10 appears twice.

**Live game:** https://myatzay.github.io/memory-matching-game/

## Game rules

- Select up to two cards at a time.
- A matching pair remains visible and increases the match score.
- A wrong pair costs one life and remains visible until the next selection.
- Match all 10 pairs before the 10 lives run out to win.

## Run locally

```bash
npm install
npm run dev
```

## Verify the production build

```bash
npm test
npm run lint
```
